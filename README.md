# SkillBridge – Youth Employability Platform

## Project Overview

SkillBridge is a MERN Stack-based youth employability platform designed to help students improve their skills and career opportunities.

## Technologies Used

* React.js
* Node.js
* Express.js
* MongoDB
* JavaScript
* CSS

## Features

* Student Dashboard
* Profile and Skills Management
* Skill Assessment
* Skill Gap Analysis
* Course Recommendations
* Job Listings
* Application Tracking
* Resume Builder
* Admin Dashboard

## Project Structure

* `client/` – React frontend
* `models/` – MongoDB models
* `routes/` – Backend API routes
* `index.js` – Express backend server

## How to Run

### Backend

```bash
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm run dev
```
